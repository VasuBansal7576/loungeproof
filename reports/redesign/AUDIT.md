# LoungeProof redesign audit · 3 October 2026

Checked the existing app at 1470px desktop and captured before-home and before-result images. The first interface worked but the reading hierarchy and delivery were weak.

1. Starting a trip: small text and a long form made the main action harder to find. Changed to a large departure-board hero, a clear CTA and four examples that fill and run the check in one action.
2. Reading an answer: the answer appeared below the fold without drawing attention. Added an automatic result reveal, a prominent verdict, a quarterly-visit graphic and three focused views: decision, original evidence, live agent.
3. Following evidence: sources and precedence were difficult to notice. Added current/historical source roles and a clickable source-decision explanation.
4. Video: six similar screenshots and static annotations made the first cut feel repetitive. Rebuilt the story with Pip, purposeful rule animations and real redesigned UI captures.

Evidence files: 01-before-home.jpg, 02-before-result.jpg, 03-new-home.png, 04-icici-result.png. This is a visual and interaction audit, not a full assistive-technology accessibility audit. Responsive and keyboard checks are recorded in QA.md.
